# 灰燼之冠 Ashen Crown

原創奇幻遊戲故事專案。

- `bible.md`：核心設定（世界觀、勢力、主線、玩法與敘事結合、角色）
- `daily/day-NNN.md`：每日 A+B+C 故事內容（Adventure／Background·Beat／Character）
- `storyboard/day-NNN.md`：與每日故事同編號的分鏡表（自 day-003 起）
- `program.md`：創作方針（每次動筆前必讀）
- `summary.md`：目前劇情摘要與狀態快照（每篇發布後更新）
- `experiments.md`：創作實驗日誌（版本、自評、留或丟、編輯分數）
- `REVISIONS.md`：依編輯評價的修訂紀錄
- [讀者評論與創作者回應](reviews/reader-feedback/README.md)：閱讀體驗、具體場景回饋、創作者決定與修訂後複讀；不自動改動故事。
