# 《灰燼之冠》第 7 天｜汛溝・跪著的使者
日期：2026-10-17（2026-10-17 21:00 依編輯總監 day-007 評價修訂；2026-10-18 09:00 依 day-007 諮詢回覆與複查再修）

## A｜Adventure
天亮前，無冠者與薇爾離開餘溫，往鎮外東南的汛溝走。啞灰被鈴紋綁在燈下，留在灰燈後廂，臨行前在石板上交代了一件事：汛溝只有潮退那一刻走得進去。
抵達時，汀已經在溝口的礁石上；溝的另一頭，碎片獵手洛坎帶著手下紮了營。主線推進：在潮水淹過溝底那具遺骸捧殼的雙手之前，親手碰到第二枚碎片。
結果：無冠者在潮回前觸到鹽殼，帶回仍封在鹽裡的第二枚碎片，沒有吸收。鹽殼正在裂，三天內必須決定它的去處：吸收、交給汀帶回潮淵，或另尋他法。

## B｜Background / Beat
汛溝是一道被潮氣灌滿的長溝，平時水深過胸，退潮時只剩一條條泥槽。今天溝面上浮著一層白汽，不是霧，是熱，靠近時臉頰會發燙。
節拍：①灰燈後廂・天亮前：啞灰石板「汛溝・潮退・只有・一刻」，並寫明他收過那條溝挖出的鹽灰、下到溝底還回來過兩次的只有洛坎→②往汛溝：灰霧被潮氣壓低，胸口碎片越走越燙，像被另一頭拉著→③溝口：汀在礁石上，洛坎的營地在對岸；三方隔溝對望→④潮退（倒數 UI 開始，終點是潮水淹過遺骸捧殼的雙手；溝口標石作為 UI 刻度）：泥槽露出，跪著的遺骸從水裡浮現，灰視照出它生前捧冠的殘影→⑤搶觸（可操作）：泥槽之間只能靠餘燼步跳過，無侵蝕上限 2（第 2 次即過熱、失明半秒）；洛坎的手下老鈍沿繩索垂降，鐵鉤一路逼近；第一跳後潮水提早回頭，洛坎的手下阿釘陷在泥槽裡，水漫到胸口→⑥抉擇（判定）：救人（本篇預設）＝第二跳落到阿釘身邊，過熱失明半秒，在黑裡把他拽上繩索，無侵蝕上限用完，只能踩泥走向遺骸，倒數加速；不救＝第二跳直落遺骸前（同樣失明半秒），先觸成立，阿釘由洛坎拖回但受傷；第三跳透支＝兩者兼得，但灰化擴散一格，熄聲鈴偵測距離加一級→⑦觸碰：老鈍的鐵鉤先搭上鹽殼邊緣，洛坎喊停；無冠者趕在潮水淹過遺骸雙手之前，掌心貼上鹽殼，鹽殼嗡的一聲，兩枚碎片同時發燙→⑧潮回：三方退回岸上；洛坎收手，留下三天的期限與鐵冠的消息。

## C｜Character
啞灰（石板，天還沒亮）：「汛溝・潮退・只有・一刻。」（翻面）「我・收過・那條溝的・鹽灰。下到・溝底的人・只有・洛坎・回來過兩次。」
薇爾（把繩子繞上肩）：「聽到了？一刻。慢了，你就跟那些鹽灰一起被收。」
汀（礁石上，看著對岸）：「獵手比我早到半夜。他們看見白汽了。」（低聲）「殿下夢裡只看得到這條溝，看不到溝底是誰。」（看你一眼）「我不下去。潮冠的人碰了灰冠的碎片，殿下的冠會先醒。」
洛坎（對岸喊，嗓子沙啞）：「晨燼家的丫頭！你那枚銅徽是我掛上去的，別在我的溝裡跟我搶！」
薇爾（喊回去）：「規矩也是你教的。先觸者得。」
洛坎：「去年冬天我三個人死在這條溝，就為了今天。這塊是他們家的撫卹。」
（潮退，跪著的遺骸露出水面）
灰之聲（很輕）：「這個人。前一夜他跪在我面前；碎冠那晚，他捧冠上來的時候，手在抖。」
無冠者：「他捧的是你的冠？」
灰之聲：「他把它封起來，是怕它叫人。……現在它叫到你了。」
汀（看見袖口的潮冠紋，把自己的袖口往掌心裡收了收）：「那是我們家的線。」
（第一跳之後，潮水提早回頭，洛坎的手下陷進泥槽）
洛坎（對岸吼）：「阿釘！別動，越動越陷！」
灰之聲：「碎片在等你。他不是你的人。」
無冠者：「他也不是鹽灰。」
（第二跳落在阿釘身邊——眼前一黑，半秒）
阿釘（在黑裡抓住他的手腕）：「別鬆！」
（視野回來時，繩索就在手邊；他把阿釘推上去，踩著泥走向遺骸，水已漫到膝蓋）
（老鈍的鐵鉤搭上鹽殼，再拉一下就是獵手的）
洛坎（對岸，看著被拽上繩的阿釘）：「老鈍。放鉤。」
老鈍：「頭兒，鉤子先到的——」
洛坎：「鉤子不是手。」（老鈍的鉤從鹽殼邊退開；無冠者掌心貼上鹽殼）
洛坎（停頓）：「先觸者得。……你先碰的是我的人。我認。」「鹽殼見熱就裂。我挖了二十年鹽灰，下過這條溝底兩次——第二次就是去年冬天。這塊撐不過三天。裂了，教團的鈴隔著半個鎮都聽得見。」（轉身前）「還有，鐵冠的人開了價。不是我會賣，是別人會搶。」
汀：「殿下要的不是這塊碎片。是你這個人，親眼替她看過它。」
薇爾（把鹽殼用布包好，塞回你手裡）：「三天。」（看你的左手）「吸了它，你會丟一段東西。我不管你丟什麼——別丟我名字。」
狀態變化：碎片 1／7（第二枚封在鹽殼內、未吸收）；自我值 98（維持）。外觀：未擴散（兩次餘燼步在無侵蝕上限內；第二跳過熱失明半秒，用在救人）。道具：取得「封鹽碎片」（三天內鹽殼會裂）。薇爾態度：重新託付→守門人（願意替你擋規矩，但開始怕你吸收後忘了她）。汀：確認遺骸屬潮冠密使一系，希望無冠者帶碎片赴潮淵見證。洛坎（新登場）：獵手頭目，守規矩、為死去的手下要撫卹；老鈍的鉤先到鹽殼，他以「鉤子不是手」叫老鈍放鉤，等於放棄了自己這邊的機會，態度從對手轉為欠一份情，但不放棄碎片。阿釘（洛坎手下）：獲救。老鈍（洛坎手下）：被叫回鉤子，心裡不服。灰之聲：認出遺骸是碎冠之夜捧冠的使者，說明鹽封是為了讓碎片不再呼喚；在救人與搶碎片之間，它站在碎片那邊。

## 摘要
無冠者與薇爾趕赴汛溝，潮退時溝底露出一具捧著鹽殼的潮冠使者遺骸。獵手頭目洛坎早一步紮營，潮水提早回頭時他的手下陷進泥槽，無冠者把第二次餘燼步用來救人，再踩泥搶到鹽殼；老鈍的鐵鉤先搭上鹽殼，洛坎以「鉤子不是手」叫他放鉤，讓無冠者帶回封在鹽裡的第二枚碎片。鹽殼三天內會裂，鐵冠已在開價，吸收、交給潮淵，或另尋他法，必須盡快決定。

## 後續延伸方向
- 三天期限：吸收第二枚（首次選擇失去哪類自我記憶）、交給汀帶回潮淵，或用啞灰的鐵箱灰屑重新封住。
- 跪著的使者：遺骸身上可能還有碎冠之夜的線索；汀說「我們家的線」，潮冠一系與灰冠的舊債浮上來。
- 鐵冠開價：冠冕繼承者勢力首次介入碎片市場。
- 洛坎：守規矩的獵手，欠無冠者一條人命的情，可成為對手或盟友；他死去的三個手下是否另有隱情。
