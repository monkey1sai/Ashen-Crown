## B｜Background / Beat
白天沒有燈律：擋人的是鎮民的目光與伊瑟倫不在眾目下動手的規矩；灰燈白天靠老闆娘坐門檻，來問空座的人先問過她。啞灰被標記，只能待在琥珀燈（含門燈分火）的光裡；後廂那盞分火油燈整天不熄，他白天也守在燈下，出不了燈，所以去不了阿砧家。
傳話的人只說「來」（program §4：轉折留在現場）：無冠者不替啞灰說內容，只替他請人；說不說、怎麼說，是啞灰自己的事。
北街：巳時以後店沒有全關，巡街侍僧只記名冊、不走近（bible〈公會帳房〉）。
站位（午後，後廂門口）：老闆娘站在後廂門 B 的門檻上，沒有進去；啞灰坐在後廂油燈下的鐵箱旁，離門四步；無冠者在老闆娘身後一步（前堂這一側）；薇爾替老闆娘坐在大門的矮凳上看門（門檻 UI 這段時間顯示「她在後廂門口（薇爾看門）」；未時到她回門檻，沒有人上門）。大門到後廂超過十步，大門那邊聽不見後廂說話。
節拍：①灰燈・天亮：老闆娘熄燈；薇爾從後院回來，說燈籠收了、今晚的潮不去→②大門・巳時：索倫在門檻外一步，先被問「誰叫你來的」；他帶回阿砧的娘的話，另外兩家問「誰知道」→③老闆娘先答索倫：明天巳時再來→④後廂門口・未時：她對啞灰說了話；啞灰寫字，把石板轉向無冠者→⑤判定（關係場，沒有倒數）：怎麼替一個出不了燈的人請三家→⑥他問老闆娘；她答→⑦阿砧家門口・申時：他只說「來」。

## 摘要
第 15 天天亮，東巷的燈籠從後院矮牆外收走，監誓人的車帶著賀絲回了要塞。巳時，索倫到灰燈門檻外：阿砧的娘收下「空座：不知道」，只說「他沒許我，也沒騙我」；另外兩家湊錢託他問——他不知道，那誰知道？老闆娘先答他明天巳時再來。午後她走到後廂門口，對啞灰說：「燈下的人，我認燈。那三家，我也認。」啞灰寫下他知道、他出不了燈，把石板轉向無冠者，要他替自己帶話。灰之聲要他別帶、別叫人來，說的是那箱灰屑。無冠者不替他說，請老闆娘讓三家明天到她的燈下，讓啞灰自己寫給她們看；老闆娘點頭，條件是來的人先問過她。申時，他到阿砧家門口只說了「來」；阿砧的娘說她去叫另外兩家，先在門檻上問過老闆娘。

## 後續延伸方向
- 第 16 天巳時，三家到灰燈門檻：老闆娘怎麼問、怎麼放人進門；啞灰在燈下寫給三家看的是什麼。
- 灰之聲提的是那箱灰屑，不是啞灰：三家看見鐵箱時，他會說什麼。
- 三家要的是撫卹：知道是誰賣的灰之後，要的是錢、是一句話，還是人。
- 東巷的燈籠入夜會不會回到後院矮牆外；北街的侍僧記下空座白天去了阿砧家，名冊會不會再流到東巷。
- 要塞拿到「我不上車」「不知道」：下一張帳何時、派誰來。

- day-026 評價建議 3／矛盾 3：期限並排寫出第 15 天亥時晚四刻半的夜潮，預設不去並由薇爾說出理由（溝口沒有要的、後院矮牆入夜有人看著）。
- day-026 評價可玩性備註 3：照灰之聲答「不知道」的後果在別處顯現——阿砧的娘「他沒許我，也沒騙我」，另外兩家回問「那誰知道」，壓力轉到老闆娘的門檻。本篇預設沒有照灰之聲（他要你別帶、別叫人來），預設不連兩篇順著同一個聲音。
- program §4.1 場景目的輪替：前四篇是複述、停留、認帳、被問；本篇是沒有倒數的關係場（不開口不判失敗）。灰之聲帶私心（提到那箱灰屑），指向明確、動機不明。
- program §4「轉折留在現場」：無冠者到阿砧家只說「來」，不說是誰、說什麼。
- program §2 動機：主角替別人做事前的掂量（燒巷那夜「燈下的人，我認燈」那段記憶他留著；阿砧的娘「記一遍就是一遍」）。
- program §2 世界觀：北街申時侍僧只記名冊、不走近（巳時後）；啞灰出不了燈寫在 B 段，是他不能自己去的理由。
- program §2 伏筆：另外兩家第一次有位置（鎮北，和阿砧家同一條巷），線頭可行動。
