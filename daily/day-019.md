# 《灰燼之冠》第 19 天｜第十晚・鐘樓
日期：2026-10-21（15:00 場）

## A｜Adventure
第 10 天午後，安息期限只剩今晚：月落前，空座要自己走到鐘樓。偵測加成 0、欠 0，熄聲鈴本輪 0 聲。本篇目標：月落前走到鐘樓，在伊瑟倫看手之前開口，讓名冊上「滿了沒有」由自己的嘴說，而不是由他的眼睛。
結果：梆子響過、點燈之後，兩人走出灰燈的門燈，守燈外的焚燒派照規矩把他們「帶到鐘樓前」。廣場西側停著監誓人的車，燈籠押著兩人從五步外經過，秤盤只抖、沒有沉。伊瑟倫站在掃淨的石上念名冊，念完就要看手；念到第三行，監誓人舉起從公會帳本抄來的一行字，當眾念出。本篇預設無冠者等那行字落下，才把上一個空座在門縫裡說的那句話說給伊瑟倫聽。伊瑟倫沒有看手，名冊改記「滿了沒有，等他自己說」，安息期限撤了；他也說出一件他自己做過的事。葛勒帶走一半的燈籠，監誓人調轉車頭。月落前，兩人回到灰燈。

## B｜Background / Beat
鐘樓廣場每天天亮掃灰，伊瑟倫說話站在石上（day-015 起），今晚台階前一粒灰都沒有，聽灰在這裡用不上。燈律不護廣場：這裡沒有掛燈之門。監誓人的車停在廣場西側，膝上那把秤換到手上提著；三步之內秤得出空座，燈籠押人走的是廣場中線，離車五步。伊瑟倫判人的做法（啞灰 day-005 喝灰粥那天親眼見過）：先把名冊上這個人的每一行念完，念的時候不停、也不抬頭，被念的人開口，他的聲音只是低下去；念完說「伸手」，才看。他看之前聽到的最後一句話，就是他記著去看的那一句。啞灰見過的只有前半（念完才看，所有路線都知道）；「話要在最後」是老莫 day-018 給預設路線的時機。鐵冠契紙留在後廂：鐘樓沒有潮，鐵印不會熱，帶著它走過監誓人的秤，等於把收據一起遞過去。
節拍：①灰燈後廂・午後：啞灰寫出伊瑟倫念完才看；薇爾說出跟去的理由與不帶契紙→②黃昏・梆子：各戶爬梯點燈，老闆娘站在門檻上（「出了這道光，我就不認了」）→③燈線外：焚燒派的燈籠圍上來（「出燈的人，帶到鐘樓前」）→④鐘樓廣場西側：押過監誓人的車前五步，秤盤的顫聲；監誓人手上捏著一條紙→⑤判定（倒數＝伊瑟倫念名冊 7 息，終點＝第 7 息「伸手」＝判定：那一刻你的話還沒說完，進失敗分支「逾時」）：規則 UI 寫出每息念哪一行：1 台階的灰｜2 兩枚，自己說的｜3 西街，午前（同一息監誓人念帳）｜4 鎮北，午前｜5 期限，第十晚月落｜6 你自己來了｜7 伸手；你的話：說那個人的話 3 息／說「還沒滿」2 息／不開口 0 息。判定看「說完」的那一息（完成時間判定）：你的話要在第 3 息那行帳之後說完、第 7 息「伸手」之前說完，而且不能和第 3 息重疊——和帳同一息說出口的字，被監誓人當眾念帳的聲音蓋過（混音：帳在前、你的話壓在底下，伊瑟倫只聽得到帳），等於那一段要重說；第 1–3 息起說，不是在帳之前就說完（帳成了最後一句），就是有一段被帳蓋過、來不及重說，都進失敗分支「被帳蓋過」；所以說那個人的話（3 息）只能第 4 息起說，說「還沒滿」（2 息）可以第 4 或第 5 息起說（「同一息監誓人念帳」與「第 3 息之後才能開口」只在 day-018 預設路線的 UI 標出；其他路線 UI 照列每息念哪一行，但不標這兩條，要從監誓人舉紙的動作自己看出來，見路線入口）→⑥伊瑟倫的回應與葛勒、監誓人各自的動作→⑦回程・月落前：一半的燈線外沒有燈籠；老闆娘「我還認」。

失敗分支：
- 被帳蓋過（說完落在第 3 息或更早，或有字和第 3 息重疊；換算成起說的一息，就是第 1–3 息起說）：你的話不是在帳之前就說完，就是有一段被監誓人念帳的聲音蓋過，當眾最後立著的是帳。伊瑟倫一樣聽懂了你說的事（說的是那個人的話時）：筆停住，把上一個空座那行的「沒開口」劃掉——這個反應所有聽完證詞的路線都有；時機改變的只是他能不能當眾認。結果：①當著監誓人那行帳，他不能當眾改口，照樣說「伸手」，看手、說「還沒滿」，名冊記「我看的」；②監誓人趁他看手走進三步，秤到你；③他知道莫恆還活著，但門閂的事他不當眾說，劃掉那行旁邊也不寫自己的名字。
- 逾時（第 7 息「伸手」時話還沒說完）：伊瑟倫聽見的是半句（證詞沒說完整，所以沒有劃掉那一行），他說「伸手」，兩個焚燒派侍僧把你的左手架到燈籠下。名冊記「空座，沒開口」；他看完說「還沒滿」，卻不寫「我看的」，守燈外照舊；監誓人走進三步秤到你。

## 摘要
第 10 晚，梆子響過，兩人走出灰燈的門燈，守燈外的焚燒派照規矩把他們帶到鐘樓前。監誓人的車停在廣場西側，燈籠押著他們從五步外經過，秤盤只抖。伊瑟倫站在掃淨的石上念名冊，念完就要看手；念到第三行，監誓人念出從公會帳本抄來的「空座，一枚一段」。無冠者等那行字落下，才說出上一個空座從門縫塞出那頁紙時說的話：「給下一個空的人。」伊瑟倫沒有說「伸手」。他說那晚的門閂在外面，是他叫莫恆閂的，他一直在等那人開口，那人其實開過口。他不看手，撤了安息期限，名冊改記「滿了沒有，等他自己說」。葛勒帶走一半的燈籠離開；監誓人說教團不要，空座就是鐵冠的；今晚名冊還開著，鐵誓不搶，天亮名冊合上才算，說完調轉車頭往西街去。月落前，兩人回到灰燈。

## 後續延伸方向
- 葛勒帶走一半的燈籠，不再站在伊瑟倫那邊：沒有授權的焚燒派，夜裡會做什麼。
- 監誓人「天亮名冊合上，就是鐵冠的」：第 11 天天亮起，教團不再擋在中間，鐵冠白天不親自、不當街，會雇誰的手；賀絲的鏽與三家撫卹。
- 伊瑟倫要找莫恆回來「把那一晚說完」：老莫往南的路上；門閂在外面，那一晚的火是誰點的仍未揭露。
- 夜路重新通了：潮信石、汀與瑟蘭娜的冠；第 11 天未時晚兩刻半的潮。
- 公會帳本：之後每說一件還記得的事，都會記進帳本，鐵冠出得起錢。
