# 《灰燼之冠》第 3 天｜燈律之夜
日期：2026-10-15

## A｜Adventure
入夜，教團審判官伊瑟倫帶著兩名侍僧從西柵進入餘溫，手提一枚「熄聲鈴」：鈴聲經過之處，碎片會被引出共鳴。主線推進：伊瑟倫沿石巷一路搖鈴到灰燈旅店，向老闆娘詢問「從王座廢墟出來的人」。無冠者在後廂必須壓住胸口碎片的脈動，熬過門外的鈴聲（屏息段落）。因為餘溫的「燈律」——琥珀燈點亮之後，任何人不得破開掛燈之門——伊瑟倫沒有硬闖，只隔著門跟薇爾說話，留下一截燒盡的燭芯和一個邀約：明日正午，他在鐘樓前施粥；若薇爾想知道妹妹最後那句話的「下半句」，就去找他。
支線：伊瑟倫離開後，後廂門把上多了一圈藍銀線，線上綁著一枚「潮貝」。貼耳可聽見一個女人的聲音：「王座生還者——井裡的名字，不要說給教團聽。月落前，到鎮南潮信石。」主線在此分岔成兩個邀約：正午的鐘樓（教團）與月落前的潮信石（潮邊來的女人）。

## B｜Background / Beat
夜裡的餘溫比白天更安靜。銅鈴被風撥動的聲音之外，多了一種更低、更沉的鈴聲——熄聲鈴不是在響，而是把周圍的聲音吸走，每搖一下，巷子裡的活灰就往地面伏低一寸。
節拍：①黃昏點燈：老闆娘爬梯點亮門前琥珀燈，薇爾說明燈律（教學：掛燈之門為安全區，敵方 NPC 不可破門）→②熄聲鈴入鎮：鈴聲沿石巷推近，活灰伏地，屋頂銅鈴一個個停擺→③屏息段落：鈴聲每靠近一次，碎片脈動 UI 就跳高一格；玩家需配合節奏按住「屏息」，讓脈動落在鈴聲的空拍裡，失敗三次則碎片外洩，門外侍僧察覺（不破門，但教團警戒度上升）→④門內外對話：伊瑟倫溫和地說話，薇爾握刀抵門，燭芯從門縫推進來→⑤鈴聲遠去，門把上出現藍銀線與潮貝；無冠者左手指尖第一次浮現灰白紋路（外觀灰化開始）。

## C｜Character
老闆娘（點燈，不回頭）：「燈亮了，門就是我的。誰想進來，先得把燈熄了——而熄燈的人，餘溫不留。」
伊瑟倫（門外，聲音很輕）：「晨燼小姐，我不是來搶東西的。碎片不是東西，是傷口。我只是想讓傷口停止流血。」
薇爾（刀背抵門，咬牙）：「三年前你也是這麼說的。然後你把她帶走，送回來的只有一罐灰。」
伊瑟倫（停頓良久）：「她走之前說了一句話。你只聽到前半句——『它在叫我的名字』。後半句，我替你留著。明日正午，鐘樓前，我施粥。」（燭芯從門縫推入）「熄滅不是殺死，是讓人安息。也替我向你身邊那位問好——他的心跳，比鈴還響。」
灰之聲（鈴聲最近時，像被掐住喉嚨）：「那鈴……是用我的骨頭鑄的。別讓它聽見你。」
無冠者（壓著胸口，低聲）：「你的骨頭？」
灰之聲：「碎冠之夜之後，他們把能撿的都撿走了。冠冕碎了，王也一樣。」
潮貝中的女聲（貼耳）：「王座生還者——井裡的名字，不要說給教團聽。月落前，到鎮南潮信石。」
灰之聲（第一次沉默很久，然後很輕）：「……潮。這個聲音，我聽過。在跪著的人裡。」
薇爾（盯著燭芯，又看你的手）：「你的指尖白了。」（把燭芯收進懷裡）「我想去鐘樓。我知道那是陷阱，可那是她的最後一句話。」（抬眼）「潮信石那邊，你想去，我不攔——但月落前我要知道你還記得我叫什麼。」
狀態變化：碎片 1／7；自我值 98（維持；屏息段落失敗不扣自我值，只提高教團警戒度）。外觀：左手指尖首次灰化。薇爾態度：主動共查→動搖（伊瑟倫握有妹妹遺言後半句，她與你的優先順序第一次分歧）。伊瑟倫：首次與玩家隔門交鋒，已察覺無冠者存在，選擇以燈律為由不破門、改用邀約。灰之聲：揭露熄聲鈴以舊王遺骨鑄成，並認出潮貝中的聲音屬於「跪著的使者」一系。潮邊來的女人：首次直接接觸，以潮貝傳話，警告勿向教團透露井中之名。

## 摘要
伊瑟倫攜熄聲鈴入夜進鎮，在燈律保護下隔著旅店門與薇爾對話，以妹妹遺言的後半句邀她明日正午到鐘樓；無冠者熬過屏息段落，指尖開始灰化。鈴聲遠去後，潮邊來的女人用潮貝傳話，邀無冠者月落前到鎮南潮信石，兩個邀約讓主線分岔。

## 後續延伸方向
- 分岔選擇：先赴月落前的潮信石（潮冠線、瑟蘭娜或密使現身），或等待正午陪薇爾去鐘樓（教團線、妹妹遺言後半句）；兩者時間相鄰，可能無法完全兼顧。
- 熄聲鈴以舊王遺骨鑄成：教團手上可能還有其他「灰王遺物」，可成為追查與奪回的支線。
- 灰之聲認出潮貝女聲出自「跪著的使者」一系，與 day-001 潮冠紋章殘影、day-002 半名「……蘭」逐步收束。
- 指尖灰化是外觀侵蝕的起點；之後吸收第二枚碎片時，首次「選擇失去哪類自我記憶」。
- 燭芯可作為道具：靠近灰燈或火源時可能顯出教團留下的訊息。
