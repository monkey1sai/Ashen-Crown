# 灰燼之冠小說閱讀版

依 day-000 至 day-042 的預設路線改編，故事截至第二十二天早晨。原始遊戲敘事稿、世界設定與分支不變。本版將舞台指示改為第三人稱敘述，補入場景銜接，合併重複說明；未採用的分支不混入正文，未解伏筆不另作解答。

- `灰燼之冠.md`：連貫小說正文。
- `灰燼之冠.html`：可離線開啟的閱讀版，含章節目錄與手機版面。
- `來源與校對.md`：章節對照、改編邊界與核對紀錄。
- `source-manifest.json`：43 篇來源與設定的 SHA-256 指紋。
- `illustrations/`：封面、人物概念及四幅章節插圖，含製作提示紀錄。
- `../output/pdf/灰燼之冠_場景插圖珍藏版.pdf`：有封面、可點擊目錄與四幅章節插圖的 A5 PDF。

執行 `python novel/build_pdf.py --scenes` 可從專案根目錄重建場景插圖版（使用 Windows 明細體與標楷體）。

修改正文後，可在本目錄執行 `python render_novel.py` 重新產生 HTML 並檢查篇章覆蓋。

來源基準：`d4a1ad4d93019f1193258026149f08e1309fbeb2`；最新篇 day-042，2026-10-29。小說化所增加的感官描寫與過場屬改編文字，不作為新增世界設定。
